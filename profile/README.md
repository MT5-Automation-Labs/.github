## 👋 About

MT5 Automation Labs builds open-source tools for automated trading on **MetaTrader 5**: Expert Advisors, risk-management modules, trade copiers and backtesting utilities. Our focus is clean, readable code with risk controls built in from the start, so traders and developers can study, test and extend each project with confidence.

## 🛠️ What We Do

- **Expert Advisor development** – custom MQL5 EAs, indicators and reusable include libraries
- **Strategy design & backtesting** – turning trading ideas into rules, then testing and optimizing them in the Strategy Tester
- **Risk management & prop-firm tooling** – daily loss limits, drawdown guards, position sizing and trade limits
- **Trade copiers & integrations** – Telegram signal copiers, TradingView-to-MT5 bridges and other connectors
- **Python MT5 automation** – bots, data pipelines and tooling built on the MetaTrader 5 Python API
