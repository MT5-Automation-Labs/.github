# MT5 Automation Labs

Algorithmic trading systems for MetaTrader 5: Expert Advisors, strategies, risk management, and automation.

## Repositories

- [mt5-xauusd-bot](https://github.com/MT5-Automation-Labs/mt5-xauusd-bot) — Python multi-strategy XAUUSD trading bot for MetaTrader 5: reads terminal data, runs technical strategies such as an HFT EMA scalper, and routes orders through a shared risk layer.
- [mt5-xauusd-gold-scalper](https://github.com/MT5-Automation-Labs/mt5-xauusd-gold-scalper) — MQL5 starter Expert Advisor and indicator templates plus a reusable include library for MetaTrader 5: conditions, order actions, money management, trailing, indicator streams and Pine Script helpers.
- [mt5-gold-scalper-ea](https://github.com/MT5-Automation-Labs/mt5-gold-scalper-ea) — MT5 gold (XAUUSD) M1 scalper EAs: Z-score mean reversion plus trend breakout, with dynamic equity risk tiers, session window, spread filter and cost-aware broker-side take-profit.
- [mt5-tradingview-bridge](https://github.com/MT5-Automation-Labs/mt5-tradingview-bridge) — Local bridge that copies trades from TradingView's Strategy Tester into MetaTrader 5: a Chrome extension reads the trade list, a Python server relays signals, and an MQL5 EA places orders with fixed lot, SL and TP.
- [mt5-backtesting-lab](https://github.com/MT5-Automation-Labs/mt5-backtesting-lab) — Rust MCP server for MetaTrader 5 strategy work on macOS/Linux.
- [mt5-telegram-signal-copier](https://github.com/MT5-Automation-Labs/mt5-telegram-signal-copier) — Python Telegram-to-MetaTrader 5 signal copier: Telethon listener, tolerant signal parser, symbol mapping, stale/duplicate checks, risk-based lot sizing, partial TPs with breakeven, CSV/JSON trade log, dry-run mode and pytest suite.
- [mt5-prop-firm-guard](https://github.com/MT5-Automation-Labs/mt5-prop-firm-guard) — Reusable MQL5 include for MetaTrader 5 that enforces prop-firm style rules: daily loss limit, static/trailing max drawdown, max open risk, trades per day, session and news windows, consistency check, auto-flatten and order blocking.
- [mt5-ema-pullback-ea](https://github.com/MT5-Automation-Labs/mt5-ema-pullback-ea) — MetaTrader 5 Expert Advisor trading pullbacks to a fast EMA in the slow-EMA trend direction, with ATR stop loss/take profit, risk % lot sizing, session and spread filters, ATR trailing stop and max positions.
